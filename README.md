# AI Career Assistanet Chatbot & Evaluation

This project provides a Streamlit chatbot application designed to help users analyze job fit and generate cover letters based on their resume and a job description. It also includes a separate Python script for evaluating the quality of the generated responses using LLM-as-a-judge techniques, including both pointwise and pairwise evaluation. ## Overview

*   **Chatbot (`app.py`):** A web-based interface where users can:
    *   Upload their resume (PDF).
    *   Paste a job description.
    *   Initialize a connection to a Generative AI model.
    *   Chat with the AI to:
        *   Get a "fit score" comparing the resume and job description.
        *   Generate an initial draft of a cover letter.
        *   Ask general questions related to the resume/JD context.
        *   Provide feedback to refine the cover letter.
        *   Save the finalized cover letter.

*   **Evaluation (`evaluation.py`):** A standalone script containing functions and classes extracted from the development notebook (`AICareerNavigator_test.ipynb`). It allows for:
    *   **Pointwise Evaluation:** Rating a single AI response against specific criteria (groundedness, fluency, instruction following, etc.).
    *   **Pairwise Evaluation:** Comparing two AI responses to the same prompt to determine which is better.
    *   Running multiple evaluation trials and saving detailed results to text files.
    *   The saved files can be edited and used for RAG(implemented in notebook) and fine tuning later.

## Features (Current Basic `app.py`)

*   PDF Resume Uploading and Parsing.
*   Job Description Input via Text Area.
*   Google Gemini LLM Initialization.
*   Chat Interface using Streamlit.
*   **Fit Score Generation:** Analyzes resume vs. job description.
*   **Cover Letter Generation (Initial Draft):** Creates a cover letter based on basic prompt.
*   **General Chat:** Basic conversational ability based on history (using LangChain Memory). Feedback loop available in notebook.
*   **RAG:** Retrival Augmented Generation using vector database and embedding, currently only in notebook. The chatbot should be 
able to retrieve from example letters and generate content that best fit the preferred writing style.

## Setup

1.  **Clone/Download:** Get the project files.
    ```bash
    # git clone <repository_url> # If using Git
    # cd aicareerchatbot
    ```
    Or simply create a directory named `aicareerchatbot` and place the files inside.

2.  **Create Virtual Environment (Recommended):**
    ```bash
    python -m venv venv
    source venv/bin/activate  # On Windows use `venv\Scripts\activate`
    ```

3.  **Install Dependencies:**
    ```bash
    pip install -r requirements.txt
    ```

4.  **API Key:**
    *   Create a file named `.env` in the `aicareerchatbot` directory.
    *   Add your Generative AI model API key to it:
        ```.env
        GOOGLE_API_KEY="YOUR_GOOGLE_API_KEY_HERE"
        ```
    *   **Important:** Add `.env` to your `.gitignore` file if using Git to avoid exposing your key.

5.  **Resume:**
    *   Replace the placeholder `my_resume.pdf` with your actual resume PDF file. Ensure it's named `my_resume.pdf` or modify the `RESUME_FILENAME` variable in `app.py`.
    *   **Privacy:** Ensure your resume PDF does *not* contain sensitive personal information you don't want processed by the LLM (e.g., full address, sensitive personal IDs).

6.  **(Optional) RAG Examples:**
    *   If you plan to run RAG-based evaluations from the notebook or potentially integrate RAG into the app later, create the `RAG_examples/` directory.
    *   Place relevant example `.txt` files inside (e.g., good cover letters, relevant job descriptions).
    *   Since cover letter is highly personal, it's recommended to upload one that fits your need and writing style.

## Running the Chatbot

1.  Make sure your virtual environment is active.
2.  Navigate to the `aicareerchatbot` directory in your terminal.
3.  Run the Streamlit app:
    ```bash
    streamlit run app.py
    ```
4.  The application will open in your web browser.
5.  **Usage:**
    *   Use the sidebar to upload your resume (`Load Uploaded Resume` button).
    *   Paste the target job description into the text area.
    *   Ensure the API key is loaded/entered and click `Initialize LLM`.
    *   Once ready, use the chat input at the bottom to interact:
        *   Type "fit score" or "analyze fit" to get the fit analysis.
        *   Type "draft cover letter" or "write cover letter" to generate the initial draft.
        *   Ask other questions related to the job or resume.

## Running Evaluations (`evaluation.py`)

The `evaluation.py` script is **not run directly** like the Streamlit app. It contains functions and classes designed to be **imported and used** in another Python script or Jupyter notebook (like the original `AICareerNavigator_test.ipynb`).

1.  **Purpose:** To assess the quality of outputs generated by different models or prompts (like those potentially generated by `app.py` or during development in the notebook).
2.  **How to Use (General Concept):**
    *   Generate some text outputs (e.g., cover letters, fit scores) using `app.py` or directly using the generation functions from the notebook.
    *   In a separate script/notebook:
        *   Import functions/classes from `evaluation.py` (e.g., `eval_task`, `eval_pairwise`, `ModelComparisonRunner`).
        *   Import necessary generation functions (like `generate_cover_letter_rag`) if you are comparing different generation methods.
        *   Load your resume and job description content.
        *   Initialize the necessary LLM objects (e.g., `ChatGoogleGenerativeAI` or any other LLM model such as OpenAI).
        *   Call the evaluation functions (`eval_task`, `eval_pairwise`) or instantiate `ModelComparisonRunner`, providing the generated text, original prompts/context, resume/JD, and LLM instances as required by the specific function signature.
    *   The evaluation functions will use the `genai.Client` (initialized within `evaluation.py`) to call the LLM-as-a-judge.
    *   if using OpenAI models, can consult [`LangSmith` documentation](https://docs.smith.langchain.com/evaluation?_gl=1*1icybxt*_ga*NjEyMTU3NzU2LjE3NDU3MzI3NzI.*_ga_47WX3HKKY2*MTc0NjA1ODgxNS42LjAuMTc0NjA1ODgxNS4wLjAuMA..) for evaluation
3.  **Output:** The evaluation functions/runners will typically:
    *   Print evaluation scores and reasoning to the console.
    *   Save detailed comparisons and verbose evaluations to text files (e.g., `pointwise_comparison_result.txt`, `comparison_results.txt`, `cv_comparison_details.txt` as seen in the notebook).

## Dependencies

Key libraries used:

*   `streamlit`: For the web application interface.
*   `langchain`, `langchain-google-genai`, `langchain-community`, `langchain-chroma`: For LLM interaction, prompts, memory, document loading, RAG, and vector stores.
*   `google-generativeai`, `google-api-python-client`: Google AI SDK for backend calls and evaluation., can substitute for other commnon AI models OpenAI's gpt-4, or Meta's Llama 3
*   `python-dotenv`: For loading environment variables (API key).
*   `pypdf`: For loading and parsing PDF resume files.

*   **Privacy:** This application processes your resume and job description content using a third-party LLM. **Do not upload resumes or paste job descriptions containing highly sensitive personal information you are uncomfortable sharing.** Remove details like specific addresses, phone numbers, personal IDs, etc., before using.

*   **Demo Purpose:** The provided `app.py` is a basic implementation. The notebook explores more advanced concepts like RAG and detailed evaluation which might not be fully reflected in the current app version. (RAG is to be added in)
